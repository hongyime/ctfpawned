5. Ask the viewer for the private incident note.

The target was vulnerable because it tried to block dangerous strings instead
of resolving the final path and checking where it landed. A path can be written
in more than one form. Removing one suspicious substring does not prove the
remaining path is safe.

## The fix

Canonicalize the requested path, then verify that the canonical result is still
inside the allowed directory. Reject anything outside that directory before
reading the file.

```js
import path from "node:path";

const publicRoot = path.resolve("/srv/nine-lives/public-docs");

function resolvePublicDocument(name) {
  const resolved = path.resolve(publicRoot, name);
  const relative = path.relative(publicRoot, resolved);

  if (relative.startsWith("..") || path.isAbsolute(relative)) {
    throw new Error("Document is outside the public archive");
  }

  return resolved;
}
```

The production control is canonicalize-then-check. Do not rely on blocklists for
path traversal defense.
